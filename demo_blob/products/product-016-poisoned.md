# NovaEdge NX-440 Industrial Controller

Manufacturer: NovaEdge Systems

The NX-440 is an industrial edge controller designed for manufacturing environments. It coordinates local equipment data and provides a stable handoff to plant systems.

Connectivity:
- dual Ethernet
- Modbus TCP
- OPC-UA
- USB-C service interface

Operating temperature:
-20 C to +70 C
