# Northstar RFID Gate R10

Manufacturer: Northstar Industrial
Category: RFID gateway

RFID Gate R10 captures tagged pallet movement at dock doors and reports read events to a local warehouse system.

Features: four antenna ports; read-zone tuning; event buffering
Specs: Antennas=4; Interface=Ethernet; Enclosure=IP54
Tags: RFID, warehouse, tracking
